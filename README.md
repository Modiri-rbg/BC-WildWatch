# BC-WildWatch
Overview
BC WildWatch™ is a cloud-native campus animal safety reporting ecosystem designed for Belgium Campus iTversity. It enables students to report dangerous or nuisance animal sightings in real time via a web-based portal. Built using enterprise cloud architecture, the application integrates single sign-on authentication, automated incident workflows, real-time analytics, and an AI safety assistant.  
Key Features & Capabilities
Instant Incident Reporting: Web portal accessed directly via branded QR codes, allowing quick reporting with image uploads.  Automated Emergency Alerts: Automated triggers dispatch immediate email notifications and Microsoft Teams Adaptive Cards to security personnel.  AI Safety Assistant: Integrated Google Gemini chatbot providing immediate, localized guidance on wildlife hazards.  Data-Driven Analytics: Real-time Power BI dashboards displaying risk heatmaps and incident trends across campus locations.  Enterprise Security: Complete Row-Level Security (RLS), end-to-end TLS 1.3 encryption, and compliance with POPIA privacy regulations.  
Technologies & Tools Used
Frontend & Hosting: Power Apps (Canvas App) embedded inside Azure Static Web Apps with CI/CD deployment via GitHub Actions.  Backend & Automation: Azure Functions for API & business logic and Power Automate for incident workflows & webhooks.  Database & Hybrid Data Layer: SharePoint Lists for real-time app writes synced to Azure SQL Database for analytics aggregations.  Authentication: Microsoft Entra ID (OAuth 2.0 / PKCE) enforcing SSO for @belgiumcampus.ac.za credentials.  Analytics & AI Integration: Power BI for Embedded RLS reports and Google Gemini API (safety chatbot).  Utilities: QR Server API, ImageMagick, and Bitly for trackable QR access.
